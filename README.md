# 🎵 Music Xuân Công - Web Nghe Nhạc & Lưu Playlist Cá Nhân

Web nghe nhạc riêng tư chỉ âm thanh, tìm kiếm thông minh theo lời bài hát, hỗ trợ nghe online, tải offline và điều khiển từ màn hình khóa điện thoại (MediaSession).

## 🚀 Triển khai lên Cloud (Render.com) miễn phí vĩnh viễn:
1. Đăng nhập [render.com](https://render.com) (chọn Sign in with GitHub).
2. Bấm **New +** -> chọn **Web Service**.
3. Chọn Repository GitHub `music-xuan-cong`.
4. Điền cấu hình:
   - **Name**: `music-xuan-cong`
   - **Environment**: `Node`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
   - **Instance Type**: `Free`
5. Bấm **Create Web Service**. Chờ 1-2 phút là bạn có link vĩnh viễn (ví dụ: `https://music-xuan-cong.onrender.com`).
